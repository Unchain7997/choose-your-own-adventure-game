## Agent skills

### Issue tracker

Local Markdown: specs and tickets live under `.scratch/<feature>/`, one file per ticket in `.scratch/<feature>/issues/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), recorded as a `Status:` line in each ticket. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` and `docs/adr/`, plus the existing ADR at `docs/0001-add-italian-language-support.md`. See `docs/agents/domain.md`.
